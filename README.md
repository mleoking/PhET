# Welcome to PhET

The **Physics Education Technology (PhET)** project produces educational simulations to promote scientific education.

Visit the website:  
[PhET Project Website](http://phet.colorado.edu)

See `LICENSE.txt` for the software license.

---

# Description of Directories

## `assets`

Artwork, audio, and other resources that are useful across the entire project.

These files are usually stored in the resource's original format (for example, Photoshop files) before being converted into a deployable format (for example, PNG).

---

## `build-tools`

Support files for compiling and running PhET simulations.

See:

- `build.bat` for Windows
- `build.sh` for Mac and Linux

---

## `doc`

Various documents that apply to the entire project.

---

## `ide`

Files for various Integrated Development Environments (IDEs), including:

- Eclipse
- IntelliJ IDEA

---

## `simulations-common`

Files shared across all types of simulations, such as software agreements and common resources.

---

## `simulations-flash`

Contains all Flash-based simulations.

---

## `simulations-flex`

Contains all Flex-based simulations.

---

## `simulations-html`

Contains experimental HTML5-based simulations.

---

## `simulations-java`

Contains all Java-based simulations.

---

## `team`

Contains a subdirectory for each PhET developer.

Developers can store anything they want under their own directory, such as:

- Experimental code
- Prototypes
- Temporary projects

However, developers should remember that this area is publicly visible.

---

## `util`

Contains various utility programs.

Projects that are not simulations are stored here.

---

## `web`

Contains files related to the PhET website.

---

# Description of Files
